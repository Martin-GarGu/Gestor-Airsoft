# Gestor de tienda de airsoft

Aplicación desarrollada en C# para gestionar inventario y la gestión de pedidos junto a la consulta de datos de una tienda de Airsoft.

Este proyecto fue desarrollado como parte de DAM con el objetivo de poner en práctica conocimientos de programación y desarrollo de aplicaciones.

## Funcionalidades

- Login para la distinción entre administrador y empleado
- Consulta de datos para el empleado como para el administrador.
- La posibilidad de realizar comparativas de productos para ambos roles.
- Gestión de pedidos y clientes tanto para el empleado como para el administrador.
- La gestión del almacén para el administrador.

## Tecnologías utilizadas

- **Lenguaje:** C#
- **Framework o plataforma:** .NET con EntityFrameWork
- **Base de datos:** SQL
- **Herramientas:** Microsoft Visual Studio 2022, Dbeaver

## Instalación y ejecución

1. Clona este repositorio.
2. Abre la solución en Microsoft Visual Studio 2022.
3. Realiza las migraciones.
4. Ejecuta el proyecto.
